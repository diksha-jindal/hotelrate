# Code of Conduct

We want this project to be useful, welcoming, and safe for contributors of different backgrounds and experience levels.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but be clear about technical risks and tradeoffs.
- Focus feedback on code, behavior, and outcomes rather than people.
- Share enough context so others can reproduce problems and help effectively.

## Unacceptable Behavior

- Harassment, intimidation, or personal attacks
- Discriminatory language or exclusionary behavior
- Publishing private information, credentials, or session data without permission
- Repeated bad-faith disruption of issues, discussions, or pull requests

## Scope

This applies to issues, pull requests, discussions, reviews, and other project spaces.

## Enforcement

Project maintainers may edit, remove, or reject content that violates this code of conduct and may limit participation when needed to protect the project community.
